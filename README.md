# Gold Rush Reels

An independent, free-play browser recreation inspired by Aristocrat's classic Where's the Gold mechanics.

## Play

Open `index.html` in a modern browser. No build step or dependencies. For public hosting enable GitHub Pages under Settings → Pages → Deploy from branch → main / root.

## Features

5×3 reels, 25 selectable paylines, virtual credits, adjustable line bets, left-to-right wins, dynamite scatters, five-character selection, 3–10 free games, up to three golden wild symbol types, and retriggerable bonuses.

## Important limitations

This is **not** an original game copy, ROM, emulator, certified mathematical reproduction, or official Aristocrat product. Payline paths, symbols, sample paytable, symbol frequencies, and bonus odds are prototype choices, not verified original game data. No original art, audio or proprietary code is included. No real-money gambling.

The primary reference is the [Kansas regulatory summary](https://www.krgc.ks.gov/assets/files/aesecurity/Aristocrat%20Summary.pdf), page 21 (November 17, 2009).
